# Flask Notes App

A simple Notes App built using Flask.

## Features

- Create Notes
- View Notes
- Edit Notes
- Delete Notes
- Search Notes
- Timestamps
- JSON-based Persistent Storage

## Technologies Used

- Python
- Flask
- HTML
- CSS
- JavaScript
- JSON

## How to Run

1. Clone the repository
2. Install Flask

pip install flask

3. Run the application

python app.py

4. Open:

http://127.0.0.1:5000
